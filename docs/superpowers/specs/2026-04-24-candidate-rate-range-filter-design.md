# 人材一覧 単価範囲フィルター 設計書

## 概要

人材一覧ページの検索フィルタに、単価の下限・上限を数値で指定して絞り込む機能を追加する。
既存の部分一致テキスト検索（`q_rate`）を廃止し、万円単位の数値入力2つに置き換える。

## 変更範囲

`app.py` のみ。DBスキーマ変更なし。

## UIの変更

`show_candidates()` 内の検索フィルタExpander（`🔍 検索・絞り込み`）を変更する。

### 変更前

- col1: スキル, 単価（テキスト入力）
- col2: 年齢下限, 年齢上限
- col3: 希望勤務形態, 参画可能時期
- フルテキスト検索

### 変更後

- col1: スキル
- col2: 年齢（下限）, 年齢（上限）
- col3: 単価（下限）万円, 単価（上限）万円
- row2: 希望勤務形態, 参画可能時期
- フルテキスト検索

単価入力は `st.number_input`、最小値0、デフォルト0（0 = 制限なし）、ステップ1（万円単位）。

## パース関数

```python
def _parse_rate_yen(rate_str: str) -> tuple[int | None, int | None]:
    """
    単価文字列から (min_yen, max_yen) を返す。
    パース失敗時は (None, None)。
    """
```

### 対応フォーマット

| 入力例 | min_yen | max_yen |
|---|---|---|
| `"60万円/月"` | 600,000 | 600,000 |
| `"60〜70万円"` | 600,000 | 700,000 |
| `"650,000円"` | 650,000 | 650,000 |
| `"650,000〜700,000円"` | 650,000 | 700,000 |
| `"〜60万円"` | 0 | 600,000 |
| `"60万〜"` | 600,000 | ∞（None） |
| パース失敗 | None | None |

### パースロジック

1. カンマ除去: `"650,000"` → `"650000"`
2. 区切り文字（`〜`(U+301C), `~`(ASCII), `～`(U+FF5E)）でsplit。`-` はハイフンと混同するため非対応。
3. 各トークンから数値を抽出（正規表現）
4. 「万」を含む場合は×10,000
5. 「千」を含む場合は×1,000

## 絞り込みロジック

`_match_candidate()` 内でフィルタ適用。

```
filter_min_yen = q_rate_min * 10000  # 0 = 制限なし
filter_max_yen = q_rate_max * 10000  # 0 = 制限なし

候補者の desired_rate を _parse_rate_yen() でパース → (cand_min, cand_max)

パース失敗 → 除外しない（通過）

フィルタ下限が設定されている かつ cand_max が not None かつ cand_max < filter_min_yen → 除外
フィルタ上限が設定されている かつ cand_min が not None かつ cand_min > filter_max_yen → 除外
```

候補者単価が範囲形式（例: 60〜70万）の場合、フィルタ範囲との**重複**があれば通過とする。

## エラーハンドリング

- `desired_rate` が `None` または空文字 → パース失敗と同様、フィルタ通過
- 数値変換エラー → `(None, None)` を返してフィルタ通過
